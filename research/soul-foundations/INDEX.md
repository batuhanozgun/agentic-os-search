## Retrieval rule

Use each vertical's `STATE.md` plus its progressive retrieval router for the current conclusion and appropriate depth.

For Records, Work and Actors, start from the vertical's `KEY.md` or `FINDINGS-MAP.md` when a bounded later question does not require the full synthesis. Descend to topic findings, audit/source ledgers and primary sources only when the decision requires that nuance or evidence.

For Actors specifically:

`L0 KEY → L1 FINDINGS-MAP → L2 synthesis → L3 topic finding → L4A completeness/audit or L4B source ledger → L5 primary/authoritative source`.

Do not use Actors `ORIENTATION.md` as the current result; it is the initial framing. Use `FRAME-EVOLUTION.md` only when research-history/audit context is required.

Do not infer a future synthesis/layer or automatically start another vertical merely because it is a plausible next step. Repository state, completed research evidence and explicit user direction control the next research question.
