# Actors — INDEX

## Role

Canonical retrieval router for the independent Actors foundation research.

It routes readers to the shortest current surface that can answer the question. It is not itself substantive evidence.

## Preferred routes

| Need | Read first | Then if needed |
|---|---|---|
| 30-second current orientation | `KEY.md` | `FINDINGS-MAP.md` |
| Topic/question routing | `FINDINGS-MAP.md` | relevant `findings/*.md` |
| Full current Actors result | `synthesis/ACTORS-VERTICAL-SYNTHESIS.md` | relevant topic finding |
| Why research stopped / omission challenge | `synthesis/COMPLETENESS-OMISSION-CHECK.md` | source ledger + relevant finding |
| Evidence/source recovery | `evidence/SOURCE-LEDGER.md` | primary/authoritative source |
| Actors-local residual questions | `OPEN-QUESTIONS.md` | relevant topic finding |
| Records/Work/later synthesis relations | `DEFERRED-RELATIONS.md` | later independently recover the other vertical |
| Research framing history | `FRAME-EVOLUTION.md` | `ORIENTATION.md` for the initial frame |
| Current status / authorization | `STATE.md` | parent `../../STATE.md` |
| Current-vs-historical file status / version binding | `CURRENT-SURFACES.md` | re-fetch listed path if decision-critical |

## Progressive depth

`L0 KEY → L1 FINDINGS-MAP → L2 SYNTHESIS → L3 TOPIC FINDING → L4A COMPLETENESS/AUDIT or L4B SOURCE LEDGER → L5 PRIMARY/AUTHORITATIVE SOURCE`

## Current vs historical/audit

Preferred current conclusion surfaces:
- `KEY.md`
- `FINDINGS-MAP.md`
- `synthesis/ACTORS-VERTICAL-SYNTHESIS.md`
- current topic files under `findings/`
- `OPEN-QUESTIONS.md`
- `DEFERRED-RELATIONS.md`
- `evidence/SOURCE-LEDGER.md`
- `STATE.md`

Historical/audit/context surfaces:
- `ORIENTATION.md` — initial working hypotheses and alternatives;
- `FRAME-EVOLUTION.md` — how frames were strengthened, weakened or revised;
- `synthesis/COMPLETENESS-OMISSION-CHECK.md` — same-model adversarial self-review and stop rationale.

`CURRENT-SURFACES.md` is the freshness/version manifest. Direct search results can surface historical files; do not treat `ORIENTATION.md` or an earlier framing statement as the current conclusion merely because it matches the query.

## Scope guardrail

Actors is sufficiently complete only for the current independent foundation purpose and awaits user evaluation.

This index does **not** authorize:
- Records–Work–Actors synthesis;
- a SOUL ontology/architecture;
- data-model or implementation design;
- another research vertical/layer.
