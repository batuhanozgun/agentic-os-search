# Work — Vertical Research

## Purpose

Research the work problem domain independently before using it inside a broader SOUL architecture model.

The provisional target is anything that must be done, changed, investigated, decided, verified, recovered, or completed, together with the structures required to represent and control its lifecycle.

## Vertical isolation

Relations to records/artifacts, actors, authority, tools, or other domains may be recorded when material but should not redirect this vertical into those domains.

## Status

This vertical is intentionally not started yet. Its detailed research questions and internal package structure should be defined when this vertical becomes the authorised active research line, informed by but not mechanically copied from the Records / Artifacts research.

## Epistemic note

`Work` is a provisional research label, not an accepted SOUL primitive.
