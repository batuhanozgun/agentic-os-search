## Current early signal — not yet a bounded finding

The bare term `work environment` is materially overloaded. In ergonomics/human-factors usage (e.g. ISO 6385), it refers broadly to physical, chemical, biological, organizational, social and cultural factors surrounding a worker. That meaning can recreate the external/surrounding-world drift that invalidated the previous Environment vertical for this project's intended fourth research region.

Technical and digital literatures expose narrower/different neighbouring concepts, including:

- software engineering / software development environment;
- development environment;
- runtime / execution environment;
- computing platform;
- digital workplace;
- shared workspace / collaborative workspace;
- technological work environment.

No one of these is accepted as the correct frame yet.
