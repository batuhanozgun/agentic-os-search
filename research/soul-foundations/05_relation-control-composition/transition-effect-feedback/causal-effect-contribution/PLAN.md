# Cross-Ground Causal Effect / Contribution — Research Plan

**Status:** ACTIVE PLAN  
**Date:** 2026-09-06  
**Parent:** accepted `Transition / Effect / Feedback`

## Objective

Bound cross-ground causal-effect semantics without collapsing the child into:
- event chronology;
- generic provenance/attribution;
- Actor responsibility/accountability;
- Control semantics;
- general epistemology;
- or one universal root-cause methodology.

## Passes

### E0 — Canonical/current evidence recovery
Recover parent promotion logic, accepted Transition/Propagation exact-effect prerequisite, Control/Standing/Actors boundaries, causal-depth protocol, candidate-study pressure and authoritative causal traditions. Freeze falsifiers before synthesis.

### E1 — Minimum causal-effect signature
Test what a decision-critical causal claim must preserve: exact realized effect, candidate contributors with typed causal roles, relevant context/scope/time, causal contrast where material, evidence basis, confidence and unresolved alternatives.

### E2 — Causal-role / depth discrimination
Attack collapses among trigger, proximate mechanism, enabling/contributing condition, prevention failure, detection/containment failure, systemic/framing condition, necessary/sufficient/contributing cause and omission/failure-to-prevent.

### E3 — Evidence / counterfactual / competing-explanation audit
Compare temporal precedence, association, mechanism, intervention, natural experiment, counterfactual reasoning and investigative evidence. Test multiple sufficient causes, interaction, overdetermination, confounding and unresolved alternatives without requiring one causal inference method for all domains.

### E4 — Rival internal decompositions
Test candidate splits such as:
- Direct Cause / Contributing Conditions / Control Failures / Systemic Causes;
- Positive Causation / Omission or Failure-to-Prevent;
- Mechanism / Counterfactual / Statistical Causation;
- Cause / Prevention / Detection;
- Proximate / Systemic;
- Effectiveness / Root Cause / Attribution.

Promote none without distinct protected questions, failure families, evidence requirements and cross-domain recurrence.

### E5 — Authoritative external + candidate holdouts
Use independent traditions as hostile pressure, not taxonomy authority. Candidate targets include:
- NASA mishap / causal-factor guidance;
- FAA root-cause / safety-management material;
- NTSB investigative practice where useful;
- CDC causal-inference / field epidemiology guidance;
- NIST incident/risk/control-effectiveness material;
- systems safety traditions such as STPA when authoritative source material is available;
- selected scholarly causal-inference sources where first-party/primary material is accessible;
- project candidate studies only as illustrative pressure.

### E6 — Synthesis / immediate-child decision
Decide whether the child is a bounded leaf, needs immediate children, exposes a sibling correction or forces a parent/four-ground reopen.

### E7 — Adversarial closure
Attack the strongest provisional result, especially:
- generic `cause` bucket risk;
- one-root-cause bias;
- chronology/correlation overclaim;
- omission/negative-causation confusion;
- responsibility/accountability leakage;
- control-effectiveness leakage;
- causal-confidence as generic epistemology;
- under-promotion of systemic causes or prevention/detection failure;
- architecture/schema leakage.

## Required non-collapse probes

```text
realized effect != intended effect
A before B != A caused B
association != causation
trigger != complete causal explanation
proximate cause != systemic explanation
necessary != sufficient
contributing != necessary
one cause identified != complete causal model
control exists != control causally effective
control failure != Actor responsibility by identity
omission / failure-to-prevent causal claim != obligation / blame by identity
causal attribution != normative accountability
plausible mechanism != competing explanations excluded
```

## Closure criteria

Close only when:
- the protected question is coherent and irreducible;
- parent/sibling/ground boundaries are stable;
- external/candidate holdouts do not expose a live first-order gap;
- rival decompositions fail or a justified child split survives;
- causal-depth stopping criteria are explicit;
- uncertainty/alternatives remain representable;
- residuals are reopen triggers rather than hidden execution debt;
- no architecture/schema commitment is required for the Foundation result.
