# Actual Causal Contribution / Episode Causation — Research Plan

**Status:** ACTIVE PLAN  
**Date:** 2026-09-06  
**Parent:** accepted `Cross-Ground Causal Effect / Contribution`

## Objective

Bound actual-episode causal semantics without collapsing the child into:
- chronology/event reconstruction;
- generic provenance/attribution;
- one-root-cause methodology;
- Actor blame/responsibility;
- Control assurance;
- contrastive/general causal-effect estimation;
- or one causal formalism.

## Passes

### A0 — Canonical/current evidence recovery
Recover accepted parent split, exact-effect prerequisite, R06 causal-depth protocol, Actors/Control/Standing boundaries, candidate-study pressure and authoritative actual-cause traditions. Freeze falsifiers before synthesis.

### A1 — Minimum actual-cause claim signature
Test what a decision-critical actual-cause claim must preserve: exact explanandum/effect, candidate actual contributors, relevant episode context/scope/time, causal role/depth where material, mechanism/path semantics where material, causal contrast/counterfactual where material, evidence basis, uncertainty and unresolved alternatives.

### A2 — Multiple causation / omission / depth discrimination
Attack single-root and but-for simplifications. Test joint causation, multiple sufficient sets, overdetermination, enabling conditions, prevention/detection/containment failure, omission/failure-to-prevent, mitigating contribution and proximate/systemic depth.

### A3 — Evidence / competing-explanation / confidence audit
Distinguish chronology, mechanism evidence, reproduction/fault injection, intervention/removal, traces, physical evidence, investigative elimination and domain theory. Preserve observationally equivalent or partially discriminated explanations without inventing one confidence metric.

### A4 — Rival internal decompositions
Test candidate splits such as:
- Direct / Enabling / Control-Failure / Systemic;
- Positive Causation / Omission or Failure-to-Prevent;
- Mechanism / Barrier-Failure / Organizational-Systemic;
- Necessary / Sufficient / Contributing;
- Local / Distributed / Systemic;
- Cause / Mitigation / Failure-to-Prevent.

Promote none without distinct protected questions, failure families, evidence requirements and cross-domain recurrence.

### A5 — Authoritative external + candidate holdouts
Use independent traditions as hostile pressure, not taxonomy authority. Candidate targets include:
- NASA mishap investigation / causal-factor guidance;
- NTSB investigation/probable-cause practice;
- FAA safety/root-cause material;
- WHO patient-safety systems view;
- systems safety STPA/CAST material;
- DOE/energy or chemical-process incident investigation where authoritative material is useful;
- selected scholarly actual-causation / multiple-cause literature;
- project candidate studies only as illustrative pressure.

### A6 — Synthesis / immediate-child decision
Decide whether the child is a bounded leaf, needs immediate children, collapses/splits differently, or forces parent/four-ground reopen.

### A7 — Adversarial closure
Attack the strongest provisional result, especially:
- one-root-cause bias;
- chronology/provenance collapse;
- but-for as universal criterion;
- overdetermination handling;
- omission/failure-to-prevent leakage into obligation/blame;
- systemic-cause under-promotion;
- Control-failure under/over-promotion;
- causal-confidence leakage into general epistemology;
- architecture/schema leakage.

## Required non-collapse probes

```text
A before B != A caused B
trigger != complete causal explanation
proximate cause != complete causal explanation
one cause identified != complete causal model
necessary != sufficient
contributing != necessary
but-for necessity != universal causal criterion
control defect != causal contribution to exact effect by identity
causal contribution != responsibility/accountability
omission causal relevance != duty/blame
plausible mechanism != mechanism actually operated
causal relation != causal evidence != sufficient-evidence Standing
```

## Closure criteria

Close only when:
- the protected question remains coherent and distinct from contrastive causal effect;
- minimum episode-cause grammar survives cross-domain pressure;
- multiple/joint/omission/systemic causation can be represented without one-root forcing;
- causal-depth stopping rule remains usable;
- responsibility/accountability and Control boundaries remain stable;
- rival decompositions fail or a justified child split survives;
- residuals are reopen triggers rather than hidden execution debt;
- no architecture/schema commitment is required.
