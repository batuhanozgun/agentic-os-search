## Protected question

> How do exact changes, actions, events, decisions, observations and control changes propagate across accepted Foundation grounds over time; what realized effects actually obtain; what causal/temporal distinctions must be preserved; and when does a return path constitute feedback, adaptation or system evolution rather than mere observation or one-off Work?

## Research object

Transition / Effect / Feedback studies cross-ground temporal/change semantics that cannot be reduced to:
- one ground-local dynamic;
- an event record;
- a Work execution trace;
- intended outcome;
- one realized Environment change;
- one causal assertion;
- or one feedback message.

Candidate pressure includes:
- state/event/change identity;
- intended versus realized effect;
- propagation and delay;
- trigger versus cause;
- proximate versus contributing/systemic causes;
- standing/control invalidation and re-evaluation;
- revocation/update propagation;
- observation and feedback return paths;
- one-off correction versus persistent adaptation/evolution;
- partial, delayed, failed and compensating effects.

These are probes, not accepted children.

## Primary falsification questions

- Is Transition / Effect / Feedback coherent as a cross-ground composition region distinct from ground-local dynamics, Binding, Standing and Control?
- Can event/change/effect/causal contribution/feedback be collapsed without losing decision-critical failure modes?
- Is sequence enough, or must causal claims preserve mechanism/intervention/counterfactual/contribution distinctions where material?
- Which temporal distinctions are universal enough to preserve: occurrence time, effective time, observation time, reference time, propagation delay, validity interval?
- When does a Work action produce an actual Environment effect, and when is the effect absent, partial, delayed, indirect or compensated?
- How should policy/authority/control changes propagate across enforcement points and previously computed standings?
- When is a signal merely Information, and when does it close a feedback loop that changes future Work/Control/Environment/Actor behavior?
- When does repeated feedback constitute persistent adaptation/evolution rather than repeated one-off response?
- Do change/effect/causation/feedback families deserve immediate children, or do they overlap too strongly?
- Does the pass expose a missing prior distinction or an upstream parent/four-ground falsifier?
