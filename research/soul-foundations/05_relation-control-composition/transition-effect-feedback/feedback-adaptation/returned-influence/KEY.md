# Cross-Ground Feedback / Returned Influence — KEY

**Document role:** CURRENT_L0  
**Status:** BOUNDED LEAF / USER-EVALUATED / ACCEPTED  
**Date:** 2026-09-11

## Shortest result

Returned Influence is an accepted bounded diagnostic leaf with one reference-relative operative-return grammar. No immediate child is promoted.

> For a bounded system or continuing pursuit, did information about its realized condition/performance return into the relevant response process, and what claim about its operative use or effect is actually supported?

## Most important correction

```text
unchanged output != no feedback
unchanged output != proof that feedback was used
```

An active loop can select hold, continuation or inhibition. A blind system can display the same output. Evidence must distinguish the two rather than require visible mutation.

## Claim levels — not children

```text
feedback structure exists
!= active response coupling established
!= particular signal/configuration caused a specified response
!= downstream actuation/effect established
```

A specific sample need not be individually decisive for a feedback loop to be operative. Joint/redundant contributions remain possible.

## Semantic signature

Bounded system/pursuit + realized source + source-bound signal/assessment + relevant return path/consumer + applicability frame + claim level + operative response locus + downstream effect boundary where claimed + evidence/alternatives/uncertainty.

No universal numerical error, single actor, permanent change, continuous loop or visible action delta is required.

## Strong boundaries

```text
any information flow != feedback return
signal delivered/read != operative use
informed decision != executed action != achieved target
causal influence != accurate content != legitimate authority
repeated derivative reports != independent corroboration
all received signals handled != all material outcomes observed
feedback operates != beneficial/stable/safe
feedback operates != persistent adaptation
```

## Parent impact

The accepted Feedback/Adaptation two-child structure survives. The parent wording refinements discovered here are accepted with this leaf: explicit return reference, no visible-change requirement, partial response versus end-to-end effect, and qualified independence language.

## Later SOUL interpretation

A system should not mistake frequent revision for learning or internal agreement for external correctness. The valuable question is whether relevant evidence reaches the response path—and whether justified response means change, restraint or further inquiry in that situation. This is a design-evaluation lens, not adopted architecture or a new agent-control rule.
