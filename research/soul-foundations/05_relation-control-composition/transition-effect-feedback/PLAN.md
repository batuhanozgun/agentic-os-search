# Transition / Effect / Feedback — Research Plan

**Status:** ACTIVE PLAN  
**Date:** 2026-09-06  
**Parent:** accepted Cross-Ground Composition

## Objective

Bound the cross-ground temporal/change problem without collapsing it into one ground's local dynamics or into a generic event/history bucket.

## Passes

### T0 — Canonical / current evidence recovery
Recover accepted sibling results, parent residuals, ground-local dynamic boundaries, candidate-study pressure and current external holdout targets. Freeze falsifiers before synthesis.

### T1 — Minimum transition/effect signature
Test what any decision-critical cross-ground transition claim must preserve: before/after focus, change identity, participating anchors/roles, occurrence/effective/reference time, intended/realized effect, scope and validity dependencies.

### T2 — Change / effect / causation / feedback discrimination
Attack collapses among event, change, action, outcome/effect, causal contribution, observation, feedback, adaptation and evolution.

### T3 — Temporal alignment / propagation / invalidation audit
Study propagation delay, distributed effectiveness, event/observation/effective/reference times, stale standing/control, revocation, partial update, eventual consistency and compensation/recovery semantics.

### T4 — Rival internal decompositions
Test candidate child splits such as:
- Change / Effect / Feedback;
- Event / Causation / Adaptation;
- State Transition / Propagation / Feedback;
- Intended / Realized / Attributed Effect;
- Forward Dynamics / Return Feedback;
- Local / Cross-Ground / Systemic change.

Promote none without a stable protected question and distinct failure family across domains.

### T5 — Authoritative external + candidate holdouts
Use independent traditions as hostile pressure, not taxonomy authority. Candidate targets include W3C provenance/change semantics, distributed-systems consistency/ordering material, incident/root-cause guidance, systems engineering/feedback material and project candidate studies.

### T6 — Synthesis / immediate-child decision
Decide whether Transition / Effect / Feedback is a bounded leaf, requires children, exposes a missing sibling region or reopens parent/four-ground adequacy.

### T7 — Adversarial closure
Attack the strongest provisional conclusion, especially:
- generic dynamics bucket risk;
- collapse into Environment Domain Dynamics or Information Dynamics;
- sequence/causation overreach;
- feedback-as-information collapse;
- adaptation/evolution overclaim;
- architecture/event-sourcing leakage;
- child under-promotion.

## Required non-collapse probes

```text
state difference != known transition path
sequence != causation
trigger != sufficient cause
proximate cause != systemic cause
intended effect != realized effect
realized effect != accepted outcome
observation != feedback
feedback != changed future behavior
changed future behavior != persistent adaptation/evolution
recorded event != actual event by identity
control update issued != all enforcement points updated
standing invalidated != standing flipped
```

## Closure criteria

Close only when:
- the protected question is coherent and irreducible;
- sibling/ground boundaries are stable;
- external/candidate holdouts do not expose a live first-order gap;
- rival decompositions fail or a justified child split survives;
- residuals are written as reopen triggers rather than hidden execution debt;
- no architecture/schema commitment is needed for the Foundation result.
