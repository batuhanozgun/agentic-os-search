# Information / Representation — KEY

**Updated:** 2026-09-12  
**Role:** current compact orientation, not full evidence

Information concerns mediated informational states/representations and the dynamics that form, derive, change or expose them, distinct from actual referents, pursuits and attributed parties.

```
Information                         [accepted parent]
├─ Informational State              [accepted leaf]
└─ Informational Dynamics            [accepted parent]
   ├─ Formation / Acquisition        [accepted leaf]
   ├─ Derivation / Transformation    [three-child parent proposal; evaluation pending]
   └─ Selection / Exposure           [unresearched / inactive]
```

State preserves reference/applicability, content/form/mode, identity/equivalence and relevant qualifications. Records remains a persistence profile; Context a working representation with selection/exposure and use relations. Evidence is target-relative, not an intrinsic source subtype.

Formation's accepted result distinguishes source capture from referent truth, copies from new origins/evidence, processed records from source coverage and receipt from reference time. It allows model-mediated interleaving rather than a universal raw-first stage.

Derivation proposes separate Re-expression/Semantic Transfer, Inferential Construction/Claim Warrant and Maintained-Information Revision/Reliance Change research. A true or entailed result can be insufficient for a use; truth does not establish offered-premise warrant; a correct new analysis does not install a revised information state. These are proposed children, not completed child passes, software modules or a mandatory pipeline.

Parent acceptance is not recursive completion. Current STATE governs evaluation and next work. Same-model and source-specific verification limits remain; no automatic child, sibling, architecture or implementation.
