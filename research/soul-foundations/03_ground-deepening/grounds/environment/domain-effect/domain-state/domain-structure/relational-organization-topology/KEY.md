## Why `Topology` is dropped

`Topology` is materially overloaded:
- network topology may include node placement/interconnection and even logical flow;
- GIS topology names spatial relation families;
- higher-order network science uses graph/hypergraph/simplicial topology.

The project node is semantic, not representation-specific. `Relational Organization` is therefore the more stable label.
