## Accepted composition anchors

Binding distinguishes generic connection, semantic relation, actual binding and evidence of binding. Standing distinguishes actual qualification, assessment, recognition/acceptance and the recorded claim. Control distinguishes policy, authority, decision, enforcement, monitoring and compliance, including the difference between an enforcement point and the whole protected effect.

Transition/Propagation distinguishes requested or recorded change from realized change, local realization from full applicable propagation, and restoration from literal reversal of time. Ground-local dynamics remain Environment-local.

The causal parent retains separate actual-episode contribution and contrastive/interventional-effect leaves. Chronology is not causation; joint configurations are not automatically independent edges; contribution is not responsibility; and a defined causal target is not automatically identifiable, estimated or decision-sufficient. Transportability/interference limits remain explicit.

The Feedback/Adaptation parent separates operative return of realized-condition information from persistent future-response change. These are distinct, non-coextensive questions, not universally independent historical predicates.

## Accepted Returned Influence result

```
unchanged output != no feedback
unchanged output != proof of feedback use
return structure != active coupling != particular-signal contribution
informed response != executed action != achieved target
influence != accurate content != legitimate authority
internal agreement != independent corroboration
all received signals handled != all material outcomes observed
```

Hold, continuation or inhibition can be operative responses. The accepted parent refinements make return reference and exact response/effect locus explicit and reject a universal visible-change requirement.

Current acceptance views are clarified. The exact original integrated G-pass synthesis is preserved at the child's `synthesis/HISTORICAL-RETURNED-INFLUENCE-SYNTHESIS.md`; raw G0–G7 and source evidence remain unchanged.

## Persistent Adaptation result — proposed

The new pass proposes one history-linked retained-response-disposition grammar, not a memory architecture. Its strongest distinctions are:

```
fixed code/weights != fixed effective response regime
changed bytes/parameters != behavioral change
stored lesson != operative retained change established
no natural recurrence yet != no latent disposition
historical acquisition != current retention != current expression
local realization != system-wide retention
adaptation occurrence != benefit != authority != transfer
```

A claim needs a justified opportunity class or continuation sequence, horizon, lifecycle boundary and support conditions. Testing may itself update the target. Evolution is not universally reduced to this leaf. Acquisition/Retention/Expression was the strongest rival split; the pass retains those failure facets without promoting immediate children at this depth.

These refinements await user evaluation and must not be presented as already accepted parent amendments.
