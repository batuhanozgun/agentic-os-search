## Preserved distinctions

Actual reality is not its representation. Work completion is not outcome attainment or authorized acceptance. Capability, authority, access and effect reach differ. Qualification differs from assessment/recorded label. Policy, decision and enforcement differ. Change is not causal proof. Stored lessons or changed code do not establish retained response change.

Formation separates capture, source coverage, copies, evidence and reference time. Derivation separates transfer, warrant and continuing-state revision. Re-expression separates possible recovery, intended meaning and actual use. Warrant preserves conditional validity, applicability, scoped uncertainty, causal identification, defeaters, evidence selection and action authority. Revision retains support/withdrawal, alternatives/policy, future-update state, time, realization and replay/current authority.

Selection separates need-to-view adequacy from information-to-consumer availability. Relevant items may form an insufficient set; a miss has claim-relative meaning; best effort is not sufficiency; exact fragments and jointly appropriate versions matter. The planned bundle can differ from the supplied one.

Accepted U5 distinguishes action from rationale/audit requirements, one witness from alternative supports, refutation from bounded certification, joint/contextual value from item-only scores, and contingent reading from fixed bundles or evolving needs. Present selection is not future disposition.

Proposed E5 qualifies target/consumer/mode, temporal/actionable access, observation scope, source change versus retained views, and supported representation versus understanding. A locator can be enough for a locator task; a static path or accepted request need not establish content in a particular invocation. Restricting a source does not prove every copy disappeared. Opportunity/presentation remains a serious rival to the proposed leaf. No fixed delivery pipeline, universal utility function, maximal context or installed behavior is adopted.
