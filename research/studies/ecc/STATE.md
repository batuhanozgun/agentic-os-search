## What U18-F establishes

NanoClaw is a human-driven transcript REPL reached through its script/npm/skill surfaces, not an ecc subcommand or a separate research target. It reads previous history before appending the current input, sends history/selected skill text/current input to successive claude -p calls through stdin, then stores the returned string and waits for another input. Named persistence, current-input nonduplication, single-REPL sequencing and local utilities are useful implemented mechanisms.

The transcript does not save the selected model, loaded skills, source revisions, cwd or native host session. Restarting the same name can preserve dialogue without restoring its previous operating context. Skill discovery depends on cwd; requested/existing files and successfully included bytes can differ. Plain prompt labels are not native system-prompt or resume controls, while actual host permissions/configuration remain relevant.

Raw replay and parsed conversion have different fidelity. Unescaped Markdown separators inside a response can cause parsed export or compaction to omit content still present in raw history. The parser scans only the first5,000,000 string units; compaction can therefore keep a tail of an older prefix and discard genuinely newer records beyond that limit when its threshold is met. Ordinary default compaction keeps twenty message records, not a semantic summary or twenty exchanges, and creates no automatic archive. This parser cap is not a model-input budget.

Process failures can become Assistant text rather than structured attempt standing; a nonzero exit without stderr can lose its failure qualifier. User/Assistant persistence is not atomic with the external attempt. Branching copies dialogue, not project files or execution isolation, and an existing branch destination can be replaced. Windows model arguments, explicit export destinations and concurrent-file behavior retain their specific source boundaries in Note45.

These are conditional source deductions, not observed data loss, attacks or model-efficacy results.
