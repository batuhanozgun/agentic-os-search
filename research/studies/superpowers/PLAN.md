## Method/plan evolution record

### v0.1 — establishment

- Adopt gstack's source-grounded synthesis method without its subsystem taxonomy/conclusions.
- Replace the introductory linear workflow with the actual three-path contract.
- Split shared skill content from host-dependent delivery; distinguish successful envelopes from usable bootstrap.

### v0.2 — U01-B refinement

- Separate description visibility, full-body delivery, invocation, tool mapping and re-entry.
- File revision, module lifetime, session events and message arrays are different research variables.
- Tool mapping can change actor/context/task semantics, not just names.
- Procedure re-entry versus work recovery motivates U02 without proving absence elsewhere.
- Q09–Q12 retain module/session, marker, Hermes aliases and distribution seams. They do not silently become mandatory live-host campaigns.

### v0.3 — U02 refinement

- Work recovery is now source-established through SDD ledger/artifacts; U01's entry-layer limitation is not a whole-system absence claim.
- Authority must be examined across phases/routes: brainstorming approval, SDD rulings and executing-plans escalation differ. An identical skill library is not an identical human-decision contract.
- The natural unit includes instructions, concrete helpers and the receiving workspace. Prose alone misses basename collisions and Git materialization; helper tests alone miss human/controller interpretation.
- Distinguish full-path plan identity, same-path revision, generated task brief and existing completion records. Preserve the ledger-header safeguard while recording that it does not disjoin the underlying file namespace.
- Task-only extraction does not automatically carry global constraints; the controller remains a substantive information-transfer actor. This determines U03's packet analysis.
- The explicit local challenge criteria were not relaxed: cross-plan aliasing and wrong-target ignore acceptance remain failures. Descriptive observations are not safety certificates.
- METHOD v0.1 and whole-study closure criteria are unchanged. These are evidence-led plan/analysis refinements, not proof that the research method itself is independently validated.
