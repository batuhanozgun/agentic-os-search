## File roles and retrieval

Collection STATE decides which source is next. Each video STATE reports that video's research progress and authorization. META handles identity/reuse; INDEX handles retrieval; VIDEO-CATALOG is a derived view. One video's unfinished phase cannot silently replace the collection's selection decision.

A later video uses `videos/<exact-case-sensitive-id>-<stable-topic>/`. Its own source question determines the appropriate research depth; the first video's U00–U07 plan is not mandatory for all videos. No empty second-video folder is created before source identity is known.

The first folder is no longer a link-only alias. All original research lives there. The retired sibling `harness-engineering-and-evolution` is not a second package to read or continue. Historical path literals in immutable evidence describe earlier publications; use the migration record and current video INDEX to recover them.

Parent discovery: [studies INDEX](../INDEX.md) and [CATALOG](../CATALOG.md). Collection and child entries describe a hierarchy, not two independent sources of corroboration.
