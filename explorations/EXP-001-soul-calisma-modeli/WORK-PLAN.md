# EXP-001 — Yaşayan aktarım planı

Plan, işin bütününü korur; STATE güncel ilerleme otoritesidir. Alt görevlerin bitmesi tek başına arşivin tamlığını göstermez.

## 1. Kaynakları güvenceye al

1.1 Özgün altı dosyayı yeniden bul ve hash'le — yerelde yapıldı.  
1.2 Kaynak ZIP'ini bütünlük ve yol güvenliğiyle aç — yerelde yapıldı.  
1.3 Kullanıcı mesajlarını U001–U019 olarak koru — sıradaki iş.  
1.4 Assistant substantive cevaplarını S001–S018 olarak koru — ardından.  
1.5 Platform export'u ile görünür-metin aktarımını ayır; eksik arşiv iddiasını kapatma.  
1.6 Özgün eserleri repository payload'ı olarak yayımla; byte/sha doğrula — aktarım kabiliyetine bağlı.

## 2. Düşünce gelişimini işle

2.1 Öğrenme kayıtlarını kaynak mesajlarına bağla.  
2.2 Yanlış anlaşılmaları ve düzeltilen görüşleri ayrı kaydet.  
2.3 Konsolidasyon sonrası mekanik modelleme ile Atlas sonrası yaşayan plan tartışmasını ayır.  
2.4 Açık soruları sonraki yetkilendirilmemiş işten ayır.

## 3. Yeniden çağırma yolları

3.1 Kütüphane girişleri ve root README — bu checkpoint.  
3.2 Research root'una sınıf sınırını koruyan kısa cross-link — daha sonra.  
3.3 Örnek/anahtar sözcük → konu → mesaj/eser → araştırma kaynağı yolu.  
3.4 Sonraki EXP paketlerinde kaynak devralma ve sorgulama ilişkileri.

## 4. Doğrulama ve kapanış

4.1 Sıra/rol/mesaj coverage kontrolü.  
4.2 Manifest/hash/ZIP/tekrar kopya kontrolü.  
4.3 Yerel ve remote payload ayrımı.  
4.4 Son commit'i readback; izinli path dışı değişiklik olmadığını kontrol et.  
4.5 Paket STATE ve kullanıcıya rapor; eksik varsa exact devam noktası.

## Durma koşulu

Sınıra gelince yeni soyut tasarım açma. Mevcut kaynakları ve sıradaki hareketi kaydet. Remote yayın olmadığı halde tamamlandı deme. Görünür diyalog aktarımı platform tarafından export edilmiş kaynak diye sunulmaz.
