# EXP-004 — Nitelendirmeler ve kanıt sınırları

Bu dosya arşivleme sırasında yapılan epistemik kontrolü taşır. Özgün U/S kaynakları değiştirilmez.

## Q01 — “Foundation kırılmadı”

Stress test boyunca Work / Actors / Information / Environment + Composition ayrımları kullanılan sentetik vakaları taşıdı. Bu, Foundation'ın exhaustive, evrensel veya bağımsız doğrulanmış olduğu anlamına gelmez. Vaka aynı assistant tarafından üretildi/yorumlandı ve Foundation zaten kullanılan frame idi; ortak kör nokta mümkündür.

## Q02 — “SOUL işe göre genişliyor”

Kullanıcının U010 farkındalığı ve sonraki Information/Environment/verification/recovery testleri bu hipotezi destekleyen kavramsal uyum gösterdi. Gerçek SOUL runtime veya implementasyon yoktur. “Baz SOUL + expanded SOUL” mimari kararı değildir.

## Q03 — Matematik soru bankası

Sentetik fixture'dır. Gerçek müfredat, pedagojik standart, öğrenci sonucu, hukuk/telif veya publishing iddiası araştırılmadı. Örnek domain bulgusu olarak reuse edilmemelidir.

## Q04 — Mission composite

Mission'ın beşinci ground olmayabileceği güçlü modelleme sonucu çıktı. Bunun runtime'da ayrı persistent object veya module olmaması sonucu çıkarılamaz; conceptual ground ile implementation object farklı seviyelerdir.

## Q05 — Need/Condition/Method/Decision/Work/Action

RPD ve Foundation ile uyumlu yararlı ayrımlar olarak kullanıldı. Bunların evrensel tek Work ontology'si olduğu kanıtlanmadı. RPD'nin agent efficacy'si kendi study sınırlarında unvalidated'dır.

## Q06 — Graph'lar

Need/Condition, Work ve Artifact/Information graph'larının ayrılması kavramsal non-collapse ihtiyacıdır. Üç ayrı database/graph service veya physical schema önerisi değildir.

## Q07 — Run / Execution Attempt

Partial/unknown effect, retries, Actor loss ve reality reconciliation örnekleri ayrı Run identity'yi güçlü aday yaptı. Her işte gerekli olduğu veya nasıl persist edileceği test edilmedi.

## Q08 — Qualification Case

Composite Standing + verification stress testinden candidate object çıkarıldı. Foundation child, schema standardı veya universal verification representation değildir.

## Q09 — Verification independence

Ayrı Actor/model/agent kullanılması otomatik bağımsızlık değildir. Bu konuşmada gerçek cross-model/verifier benchmark çalıştırılmadı. “Independent solver/domain expert” örnekleri possible oracle sınıflarıdır.

## Q10 — Continuity

Conversation resume, handoff ve persistence'ın yetersiz olabileceği sentetik failures üzerinden gösterildi. Gerçek session-kill, external effect, multi-writer veya recovery experiment yürütülmedi.

## Q11 — Repository reuse

gstack, Superpowers, work-management-project-control, Beads, OpenSpec, recursive-prerequisite-discovery, context-memory-harness-engineering ve Foundation seçici biçimde yeniden kullanıldı. Bu paket ilgili source studies'in current external upstream'lerini yeniden validate etmez ve araştırmaları mimariye promote etmez.

## Q12 — “Repository çok yararlı oldu”

Bu, kullanıcı gözlemi ve konuşmanın nitel değerlendirmesidir. Repo katkısının ölçülmüş benchmark'ı değildir. Güçlü değer, daha önce araştırılmış non-collapse ayrımları ve failure modes'u hızlıca geri çağırabilmesidir.

## Q13 — Source fidelity

Kaynak konuşma modele görünür metinden manual transcription'dır; byte-perfect platform export değildir. UI code-block IDs ve whitespace presentation farklı olabilir. Tool/progress commentary ayrı source message olarak arşivlenmez; substantive final cevaplar korunur.

## Q14 — Mimari/uygulama yetkisi

U014 repository arşiv yetkisidir. SOUL architecture adoption, Development OS implementation, yeni research campaign veya agent-control mutation yetkisi değildir.
